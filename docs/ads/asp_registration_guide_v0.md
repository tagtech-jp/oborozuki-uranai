## 3. 登録手続きフロー（社長手動・各ステップ目安時間）

### 3-1. A8.net（最優先）

**目安所要時間: 約15分**

1. https://www.a8.net/ にアクセス
2. 「メディアとして登録（無料）」をクリック
3. メールアドレス・パスワード・サイトURL（`https://oborozuki.jp`）を登録
4. **登録完了（審査なし）** → 即日から案件申請可能
5. 占い系案件を検索 → 各案件に「提携申請」→ 大半は数分〜即時承認

**A8.net での効率的な案件探しのコツ**:
- サイト管理画面 → プログラム検索 → キーワード「占い」「星座」「スピリチュアル」で検索
- 「提携許可方法: 自動承認」でフィルタリングすると即使用可能

### 3-2. もしもアフィリエイト

**目安所要時間: 約20分**

1. https://mohican.jp/ にアクセス
2. 「無料会員登録」
3. サイトURL・ジャンル（趣味・占い・ライフスタイル等）を登録
4. 登録完了後、Amazonアソシエイト連携を設定する（もしも経由でボーナスあり）
5. 占い関連書籍のリンクを生成して使用

### 3-3. afb（アフィb）

**目安所要時間: 約30分（審査1〜3日）**

1. https://www.afb.ne.jp/ にアクセス
2. 「アフィリエイター新規登録」
3. サイト情報を入力（ジャンル: エンターテインメント・占い）
4. 審査通過後（通常1〜3営業日）に案件利用可能
5. 占い・婚活・美容系の高単価案件を優先申請

### 3-4. Amazonアソシエイト（任意・相性良い）

**目安所要時間: 約30〜60分（審査あり）**

1. https://affiliate.amazon.co.jp/ にアクセス
2. Amazonアカウントでログイン → アソシエイト登録
3. サイトURL・コンテンツ説明を入力
4. 仮承認後に180日以内に3件以上の購入が発生すると本承認
5. 占い書籍・タロットカード・パワーストーン等のリンクを生成

## 4. 朧月への実装手順（別タスク・本日スコープ外）

> ⚠️ 以下は Phase 2 完了後、別タスクとして実装する（本日スコープ外）

### 4-1. ASP承認後のリンク/バナー埋め込み

1. 各ASPの管理画面からバナーコードまたはテキストリンクを取得
2. `components/ads/AspBanner.tsx`（既存プレースホルダー）に実装
   - バナー上部に `<SponsorLabel label="PR" />` を必ず追加（ステマ規制対応）
   - 実装例:
     ```tsx
     import SponsorLabel from "./AdSlot";
     // または
     import SponsorLabel from "./SponsorLabel";
     
     export default function AspBanner() {
       return (
         <div>
           <SponsorLabel label="PR" />
           {/* ASPから取得したバナーコードをここに埋め込む */}
         </div>
       );
     }
     ```

### 4-2. PR表記の配置ルール（ステマ規制対応）

- **必須**: バナー・テキストリンクの**直上または直左**に「PR」または「広告」を表示
- **必須**: 視認性確保（小字・薄色での埋没禁止）
- `SponsorLabel` コンポーネント（`components/ads/SponsorLabel.tsx`）を使用すること
- ASP固有のPR表記要件がある場合はそちらを優先する

## 5. ステマ規制 ASP固有要件

| ASP | PR表記要件 |
|-----|-----------|
| A8.net | 明示的な規定なし（景表法告示に準拠すること・と案内あり） |
| もしもアフィリエイト | 「アフィリエイトリンクを使用していることを明示してください」と規約に記載 |
| afb | PR表記の義務付け規定あり（広告主ごとに要件が異なる場合あり） |
| Amazonアソシエイト | **「Amazonのアソシエイトとして、適格販売により収入を得ています。」の文言掲載が利用規約で義務付け** |

> **重要**: Amazonアソシエイトを使用するページには上記文言の掲載が必須。  
> `/about` または各ページのフッター近くへの追加を推奨。

## 6. 優先度別 登録スケジュール

```
今すぐ（即日）:
  ① A8.net 登録 → 占い系案件に提携申請
  ② もしもアフィリエイト 登録 → Amazon書籍リンク設定

AdSense審査申請後（並行）:
  ③ afb 登録 → 高単価案件確保

サイト成長後:
  ④ Amazonアソシエイト → 180日3件ルールを満たすPV獲得後に本登録
  ⑤ ヴェルニ等の直接提携 → 十分なPV/コンバージョン実績が出たら交渉
```
